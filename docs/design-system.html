Sistema de design da UniPlace

A linguagem visual da UniPlace reúne as decisões que tornam a vida universitária mais clara, acessível e conectada.

Dark-firstAcento emeraldWCAG AAGrade de 4 pxMobile-first

A escala de 4 px é a base para distâncias e dimensões da interface.

01 / FUNDAMENTOS

Cores

A paleta parte do azul-marinho e reserva o verde para orientação e ação. Primitivas formam escalas de 950 (mais escuro) a 50 (mais claro); componentes nunca as usam direto, só os papéis semânticos.

Paleta primitiva

Papéis semânticos e contraste

As razões são calculadas no navegador. Para fundos, o teste usa texto principal sobre o fundo; para texto, usa o fundo indicado. Texto exige 4,5:1; bordas de controles exigem 3:1 (WCAG 1.4.11); divisórias e trilhas decorativas não têm requisito.

Outros papéis semânticos

Valores compostos a partir de outros tokens.

02 / FUNDAMENTOS

Tipografia

Inter quando disponível, com fallback do sistema. Os tamanhos refletem o uso real da aplicação; a amostra usa peso 400 e altura de linha 1,35.

03 / FUNDAMENTOS

Espaçamento e medidas

Use a escala de 4 px para compor ritmos. A escala limita os intervalos a passos consistentes de 4 a 80 px.

04 / FUNDAMENTOS

Raios

Controles e superfícies compartilham cantos suaves; o círculo identifica avatares e indicadores.

05 / FUNDAMENTOS

Sombras / Elevação

A borda organiza superfícies; a sombra suave destaca o cartão de autenticação.

Superfície elevada--shadow-lg

06 / FUNDAMENTOS

Movimento

O indicador de carregamento usa a curva padrão de movimento. Com movimento reduzido, animações e transições são praticamente instantâneas.

@media (prefers-reduced-motion: reduce) { animation: none; transition: none; }

09 / COMPOSIÇÃO

Padrões de layout

O container centraliza o conteúdo; o grid de cartões passa de três para duas e depois uma coluna.

Container

Largura máxima de 1200 px, com 16 px de margem lateral em cada lado.

Breakpoints

Até 900 px: duas colunas. Até 600 px: uma coluna. As media queries usam valores literais.

10 / QUALIDADE

Acessibilidade

Use HTML semântico e verifique os pares de cores no contexto real de uso.

Teclado e foco

O anel de foco permanece visível; controles frequentes têm alvo mínimo de 44 px.

Conteúdo e movimento

Associe labels aos campos, descreva erros e respeite a preferência por movimento reduzido. O contraste precisa ser verificado para cada combinação.

11 / PRÁTICA

Uso

Prefira papéis semânticos; reserve primitivas para definir ou estender o sistema.

background: var(--color-surface); color: var(--color-text); gap: var(--space-4);

Faça

Reutilize componentes, preserve estados e valide contraste, teclado e telas pequenas.

Evite

Usar cores isoladas para transmitir significado ou criar valores locais sem necessidade.

Os exemplos ilustram componentes e dados fictícios; não enviam informações para a aplicação.
